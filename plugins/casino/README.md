# Casino Mode

A neon casino visual theme for pi. It is optional and off by default.

## Command

```text
/casino
```

`/casino` toggles the mode on and off.

When enabled, it applies the casino theme across Pi's built-in interface, including messages, tools, diffs, Markdown, syntax highlighting, thinking levels, borders, and status colors. It also adds a colorful working indicator and animated status widget.

When toggled off, it stops all timers and restores the exact theme that was active before Casino Mode.

Casino Mode changes UI state only. It does not change the system prompt, tools, conversation, or model/provider cache.
