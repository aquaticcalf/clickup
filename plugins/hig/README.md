# HIG

An always-loaded visual baseline for pi inspired by Apple's Human Interface Guidelines: calm contrast, clear hierarchy, restrained color, and readable defaults.

HIG applies its theme at session startup without changing the saved user theme setting. Other visual plugins can temporarily override it; for example, `/casino` takes over while active and restores HIG when turned off.

HIG intentionally adds no commands, status messages, widgets, animations, sounds, or conversation content.
