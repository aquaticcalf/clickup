# Paste image

Makes pi's normal paste shortcut image-aware:

- Paste an image with `Ctrl+V` (or `Alt+V` on Windows).
- The image is attached to the next prompt instead of being sent immediately.
- Keep typing a caption or question, then press Enter.
- Pasting text still uses the normal editor paste behavior.

The `/paste-image` command attaches the current clipboard image without replacing the editor text.
